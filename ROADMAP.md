# Roadmap

Nexum's roadmap will evolve as the architecture is validated and community feedback is incorporated.

## Phase 1 — Core

- [ ] Rust workspace
- [ ] Domain model
- [ ] Download task state machine
- [ ] Scheduler
- [ ] Persistent storage
- [ ] Event bus
- [ ] Engine Adapter interface

## Phase 2 — Protocol

- [ ] Nexum Protocol
- [ ] Task CRUD
- [ ] Task control
- [ ] Progress events
- [ ] Authentication and authorization model

## Phase 3 — Clients

- [ ] CLI foundation
- [ ] Server foundation
- [ ] Desktop foundation
- [ ] Browser integration

## Phase 4 — Extensibility

- [ ] Plugin manifest
- [ ] Permission model
- [ ] Plugin SDK
- [ ] Resolver extensions
- [ ] Engine extensions

## Phase 5 — Media & Automation

- [ ] Media pipeline
- [ ] Automation APIs
- [ ] AI/MCP integration
- [ ] Remote device management

Roadmap items are directional rather than promises of a fixed release schedule.
